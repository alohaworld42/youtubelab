Optional character avatar images shown while each voice speaks.

File names map to speakers (transparent PNGs work best):
  narrator.png    -> shown for narrator lines (Reddit, facts, scary)
  speaker_a.png   -> first character in "Two Characters" videos
  speaker_b.png   -> second character

If a file is missing, that speaker simply shows no avatar (no error).
Square-ish PNGs around 500x500 look best. Position/size is set in config.json
under "video".avatar_*.
