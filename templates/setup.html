Setup

Einmal durchklicken, dann läuft alles. Pflicht: Schritt 1 + 2. Schritt 3 nur für Uploads, Schritt 4 optional.

1 · System (FFmpeg) prüfe…

FFmpeg fehlt. In PowerShell ausführen, dann Terminal neu öffnen und App neu starten:

winget install Gyan.FFmpeg
2 · KI-Backend (schreibt die Scripts) prüfe…

Key holen →

Kein Key nötig. Ollama muss laufen (ollama serve) und ein Modell gezogen sein (ollama pull llama3.1).

3 · YouTube-Upload freischalten prüfe…

Google erzwingt hier 5 Minuten Console-Arbeit (einmalig, für alle Kanäle zusammen):

  1. console.cloud.google.com → Projekt anlegen
  2. YouTube Data API v3 → „Aktivieren“
  3. Anmeldedaten → „OAuth-Client-ID erstellen“ → Typ Desktop-App → JSON herunterladen
  4. OAuth-Zustimmung → unter „Testnutzer“ jedes Google-Konto eintragen, dessen Kanal du verbinden willst
Weiter: Kanal verbinden →
